KB금융그룹 관리자 화면 구축

KB국민은행 본사 보안 인가 환경에서 다국어 IR 공시 및 이사회 안건을 효율적으로 관리할 수 있도록, 3단계 권한 등급(일반·관리자·승인자)에 맞춘 대용량 CMS 백오피스를 코드 기반으로 직접 설계 및 구축한 프로젝트입니다.

본사 파견 및 엄격한 보안 환경 속에서 별도의 디자인 시안 없이, 사용자 권한에 따른 3가지 어드민 UI/UX 구조를 직접 기획하고 마크업을 수행했습니다. 복잡한 다국어 공시 데이터 작성 및 결재 워크플로우를 직관적인 정보 구조(IA)로 정돈했으며, 대량의 금융 데이터 모니터링 시 시각적 피로도를 낮출 수 있도록 가독성 높은 데이터 그리드와 공통 UI 컴포넌트를 체계화했습니다. 이를 통해 일관된 어드민 UI 체계를 코드상으로 완벽히 구현하여, 권한별 화면 분기와 반응형 테이블 인터랙션이 매끄럽게 동작하는 최적의 퍼블리싱을 완료했습니다.
