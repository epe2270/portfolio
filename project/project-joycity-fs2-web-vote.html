프리스타일2 공모전 투표 이벤트

유저 참여형 BGM 공모전 출품작을 직관적으로 청음하고 실시간 투표에 참여할 수 있도록 기획부터 디자인, 퍼블리싱까지 100% 전담 구축한 프로모션 페이지입니다.

BGM 공모전 후보작 감상과 투표가 원활하도록 직관적인 동선을 기획하고, '프리스타일2'의 스포티한 네온 비주얼을 살려 디자인했습니다. 특히 음원 재생 시 플레이 버튼 바깥 테두리가 진행도(Progress)에 맞춰 실시간으로 채워지는 커스텀 인터랙션을 개발해 사용 편의성을 높였습니다. PC와 모바일 모두에서 재생 및 투표가 매끄럽게 동작하는 반응형 웹을 완성했습니다.
