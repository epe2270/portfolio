프리스타일2 10주년 이벤트

프리스타일2 출시 10주년을 기념하여 유저 감사 인포그래픽, 출석체크, 공모전, 웹 기반 보드게임 등 다채로운 이벤트를 통합 구축해 유저 참여를 극대화한 대규모 프로모션 페이지입니다.

10주년 축제에 어울리는 화려한 네온 비주얼을 바탕으로 인포그래픽, 매일 참여를 유도하는 출석체크, 유저 참여형 공모전 등 다양한 이벤트 동선을 직관적으로 기획하고 디자인했습니다. 특히 퍼블리싱 단계에서 웹 브라우저 상에 '부루마불' 형태의 미니게임을 구현하여, JavaScript 기반의 생동감 있는 주사위 롤링 이펙트와 말판 이동 애니메이션을 개발한 것이 특징입니다. 풍성한 이벤트 콘텐츠와 화려한 동적 인터랙션 요소들이 PC 웹 환경에서 끊김 없이 안정적으로 동작하도록 최적화하여 퍼블리싱을 완료했습니다.
